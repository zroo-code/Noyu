🌌 You Are My Favorite Universe

A romantic galaxy-themed website built with pure HTML, CSS, and JavaScript.

✨ Features

- Animated twinkling stars background
- Elegant romantic design
- Responsive for mobile and desktop
- Floating photo frame with glowing effect
- Smooth scrolling experience
- Love letter/story section
- Lightweight and fast (No frameworks required)

📸 Preview

Add your favorite photo by replacing:

<img src="maila.jpg" alt="Maila">

with your own image file.

🚀 Getting Started

1. Download or clone this repository.

git clone https://github.com/your-username/favorite-universe.git

2. Open the project folder.

3. Place your image inside the project directory.

Example:

favorite-universe/
│
├── index.html
├── maila.jpg
└── README.md

4. Open "index.html" in your browser.

🛠 Built With

- HTML5
- CSS3
- Vanilla JavaScript
