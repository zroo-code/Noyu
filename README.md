## 🌌 Fitur Utama

| Fitur | Deskripsi | Teknologi |
| :--- | :--- | :--- |
| **Interactive Starfield** | Latar belakang hamparan bintang malam bergerak yang kelap-kelip secara dinamis dan otomatis menyesuaikan ukuran layar. | HTML5 Canvas & JS |
| **Glow Glassmorphism** | Kartu pesan utama menggunakan efek kaca transparan blur dengan *box-shadow* neon pink yang menyala lembut. | CSS Backdrop Filter |
| **Pure CSS Flower** | Animasi tanaman dan bunga estetik yang mekar secara bertahap saat halaman di-scroll tanpa aset gambar luar. | 100% CSS `@keyframes` |
| **Auto Scaling Mobile** | Tampilan otomatis mengecil secara proporsional dan presisi saat dibuka di smartphone agar bunga tidak terpotong. | CSS Media Queries |

---

## 🛠️ Detail Teknis & Animasi

Proyek ini tidak menggunakan *framework* atau *library* eksternal pihak ketiga (Zero Dependencies). Semua animasi diatur murni melalui kode:
* **`float`**: Membuat bingkai foto utama bergerak naik-turun secara halus seolah mengambang di luar angkasa.
* **`pulseSlow`**: Memberikan efek detak jantung pada emoji sambutan dan ikon hati penutup.
* **`light-ans`**: Mengontrol partikel cahaya (*fireflies*) yang terbang ke atas dari sela-sela tangkai bunga.
